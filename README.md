# ⚡ MetalsTerminal (메탈스터미널)

> **국제 금속 시세·스크랩·폐촉매 데이터 터미널 & 품목별 리포트 포털**  
> 모바일 극단적 가독성 시세표, 30일 시계열 차트 & 조달청 고시가 비교, 정밀 스크랩 산출 공식 가이드, 12개 품목별 실시간 뉴스 결합 AI 시장 및 스크랩 여파 분석.

---

## 🚀 핵심 서비스 구성

1. **📊 국제 금속 시세 (`price.html`)**
   - 12개 품목: 철스크랩, 구리, 알루미늄, 아연, 납, 니켈, 주석, 백금, 팔라듐, 로듐, 금, 은
   - 실시간 하나은행 환율 연동 원화 환산가 및 전일비 등락률
   - 품목 행 클릭 시 **30일 시계열 SVG 라인 차트 & 조달청(PPS) 비축물자 판매고시가 비교** 아코디언 토글
2. **🏗️ 스크랩 & 폐촉매 시세 (`scrap.html`)**
   - 상단 **[📐 스크랩 산출 공식 안내 아코디언]** (철 5등급, 구리 3등급, 신주 3등급, 알루미늄 4등급, SUS 304, 폐촉매 실거래 수율 산출 공식 투명 공개)
   - 상단 **[🏛️ 조달청(PPS) 비축물자 판매고시표]** (전기동, 알루미늄, 아연, 납, 주석, 니켈)
   - 철스크랩 5등급(생철A, 중량A, 중량B, 경량A, 선반설), 비철 실거래 단가표, 차종·엔진별 순정 폐촉매 실거래 매입단가표
3. **📰 품목별 일일 리포트 (`report.html`)**
   - 12개 품목 전수 실시간 Google News RSS 크롤링 (최근 7일 기사 5건)
   - 품목별 피드 및 개별 정적 아티클(`articles/*.html`) 자동 발행
   - **AI 시장 및 스크랩 여파 분석**: 1. 이슈 판정, 2. 핵심 내용 요약, 3. 향후 시장 여파 및 전망 코멘트 (원자재 수급 전망, 자동차 부품 원가 및 스크랩 유통 영향)
4. **🛒 통합 직거래 장터 & 💬 커뮤니티 (`index.html`)**
   - 로그인·회원가입 없는 3초 익명 직거래판 및 자유게시판

## ☁️ 100% 클라우드 무인 자동화 (GitHub Actions)

- **로컬 PC 무부하 (GPU 사용 0%)**: 로컬 PC가 꺼져 있어도 GitHub Actions 가상머신에서 단독 무인 구동.
- **스케줄러**: `.github/workflows/daily_terminal.yml` (매일 UTC 00:00 / 한국 시간 09:00 정각 KST)
- **AI 엔진**: GitHub Secret의 `GEMINI_API_KEY` 기반 Google Gemini Flash API 호출.
- **원클릭 배포**: 수집 ➔ 스크랩 계산 ➔ AI 리포트 생성 ➔ 정적 HTML 빌드 ➔ Git 커밋 & 푸시 ➔ GitHub Pages 배포까지 전 과정 100% 자동화.

## 📂 프로젝트 구조

```
metalsterminal/
├── .github/workflows/
│   └── daily_terminal.yml   # 매일 09:00 정각 GitHub Actions 무인 자동화 워크플로우
├── index.html               # 메인 포털 허브 (시세 피드 + 직거래 장터 + 자유게시판)
├── price.html               # 12개 품목 시세 & 30일 시계열 차트 & 조달청 고시가 비교
├── scrap.html               # 스크랩 정밀 공식 가이드, 조달청 판매표, 폐촉매 단가표
├── report.html              # 12개 품목별 AI 리포트 전문관
├── articles/                # 품목별 일일 정적 아티클 보관소 (*.html)
├── data/
│   ├── prices.json          # 12개 품목 종가 및 30일 차트 데이터셋
│   ├── scrap.json           # 스크랩 등급별 도소매 단가 데이터셋
│   └── reports.json         # 품목별 실시간 뉴스 및 AI 분석 데이터셋
├── pipeline.py              # 통합 마스터 파이프라인 (Actions 가상머신 단독 실행)
├── collector.py             # 경량 시세 동기화 도구
├── style.css                # 반응형 모바일 최적화 스타일
├── app.js                   # 인터랙션 (차트 아코디언, 필터 칩, 게시판)
└── TASK_HISTORY.md          # 마스터 작업 히스토리
```
