# ⚡ MetalsTerminal (메탈스터미널)

> **국내 1위 비철금속·스크랩·폐촉매 데이터 터미널 및 익명 직거래 포털**  
> 모바일 극단적 가독성 시세표(Glance Matrix), 매일 아침 9시 쉬운 리포트(매거진), 로그인 없는 3초 익명 직거래 장터 및 전용 스크랩 계산기.

---

## 🚀 핵심 기능 구조

1. **📊 오늘의 시세 & 스크랩 단가표 (The Glance Feed)**
   - 구리(A동), 알루미늄(샷시), 고철(생철), 로듐(승용촉매), 아연, 금 등 핵심 9대 품목.
   - 현장 매입 추정가(원/kg, 원/개)와 전일 대비 등락(▲/▼/─)을 모바일 화면에서 1초 만에 스캔.
   - [전체 / 비철 / 촉매·귀금속] 탭 필터링 지원.
2. **📰 오늘의 쉬운 리포트 (매거진)**
   - 매일 아침 9시 발행되는 4대 챕터 해설: [현재 상황 ➔ 재고 상황 ➔ 거시경제 ➔ 향후 예측 (면책 강조)].
   - 하단 실시간 해외 원문 기사(RSS) 출처 링크 제공.
3. **🛒 통합 직거래 장터 & 💬 자유게시판**
   - 로그인·회원가입 없는 3초 익명 직거래판 (닉네임 + 비번 4자리 + 1초 스팸방지 퀴즈).
   - 비철·고철·폐촉매·기판 구분 없는 통합 최신 매물 나열.
4. **📱 독립 스크랩 계산기 (`calc.html`)**
   - 메인 화면의 군더더기를 없애고 전용 계산기 페이지로 분리.
   - 품목 선택, 중량(kg) 및 수량(개), 현장 이물질 감가율(0~30%) 실시간 정산액 산출.

---

## 🛠️ 자동 수집 파이프라인

- **데이터 수집기 (`collector.py`)**:
  - `thepathlab/latest.json` 및 금융 환율 데이터를 읽어와 `data/prices.json`을 단 0.1초 만에 갱신.
  - 실행: `python collector.py`

---

## 📂 프로젝트 구조

```
metalsterminal/
├── index.html       # 모바일 최적화 메인 포털 (시세 + 리포트 + 장터 + 자유게시판)
├── calc.html        # 독립 스크랩 & 폐촉매 정산 계산기
├── style.css        # 도싸 스타일 고밀도 텍스트 + 모던 클린 테마
├── app.js           # 시세 렌더링, 필터링, 익명 글쓰기 인터랙션
├── collector.py     # 매일 아침 9시 시세 자동 수집/동기화 엔진
└── data/
    └── prices.json  # 정형화된 일일 시세 및 스크랩 단가 데이터셋
```
